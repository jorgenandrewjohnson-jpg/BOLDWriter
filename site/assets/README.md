# Public visual assets

- `wordmark.svg`, `favicon.svg`, and `social-preview.svg` are original BOLD Writer brand graphics created for this project. `social-preview.png` is the 1280 × 640 raster rendering of the SVG.
- `book-studio-synthetic.png` is unaltered output from BOLD Writer's native 3D acceptance renderer using a disposable synthetic illustrated manuscript and a synthetic cover. Its SHA-256 is `4f42e8965da286feccc0276ef22f59e47ceb9ee30df64fdae381254c34c33b98`. This is rendering evidence; it does not establish successful interactive GUI acceptance.

- `app-*.png` are unaltered window captures of the running macOS Release build from public source commit `a7a9380` with a disposable synthetic book. The QA build used a distinct bundle ID so the user's installed app remained untouched. These images demonstrate only the visible interactions described in the README; they do not establish full installed-app acceptance.

No production manuscript or third-party photograph is represented in these assets. The synthetic fixture and screenshots contain no personal manuscript content.
